# Geetha Kuppuswamy — Leadership Portfolio

A responsive executive portfolio highlighting 20+ years of technology program leadership across Intuit, Chegg, and PayPal.

## Highlights

- Leadership across portfolios spanning approximately 400 engineers and $125M+ in business impact
- Product and platform launches across QuickBooks, accountant, workforce, and payments ecosystems
- AI transformation, enterprise governance, M&A integration, and operating-model design
- Responsive, accessible single-page experience

## Run locally

Requires Node.js 22.13 or later.

```bash
npm ci
npm run dev
```

For a production build:

```bash
npm run build
```

## Technology

TypeScript, React, Next.js-compatible routing, Vinext, Vite, and Cloudflare Workers.
